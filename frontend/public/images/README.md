# Images MA SANTÉ

Déposer ici les images personnalisées de l'application.

Fichiers recommandés :

- `logo-ma-sante.png` : logo officiel.
- `logo-ma-sante-white.png` : version claire pour fonds foncés.
- `login-clinic.jpg` : photo d'illustration de la page de connexion.
- `doctor.jpg` : photo médecin si nécessaire.
- `clinic.jpg` : photo de la clinique.
- `favicon.png` : icône du site.

Le CSS utilise actuellement `login-clinic.jpg` comme image optionnelle de fond. Si le fichier n'existe pas, le dégradé reste visible.

Pour respecter la maquette, privilégier les visuels médicaux professionnels avec une dominante bleu/vert et une bonne lisibilité.
